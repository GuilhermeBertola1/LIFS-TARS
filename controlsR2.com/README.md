# controlsR2.com

## Objetivo

Dashboard de monitoramento e controle do Reator 2.

## Variáveis Monitoradas

* Temperatura
* Pressão
* Espessura
* Temperatura da água
* Estado do espectrômetro

## Tecnologias

* HTML5
* CSS3
* JavaScript
* Socket.IO
* Chart.js

## Recursos

* Atualização em tempo real;
* Controle remoto;
* Monitoramento contínuo;
* Integração MQTT.
