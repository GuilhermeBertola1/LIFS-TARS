# controlsR1.com

## Objetivo

Dashboard de monitoramento e controle do Reator 1.

## Variáveis Monitoradas

* Temperatura
* Pressão
* Espessura
* Temperatura da água
* Estado do espectrômetro

## Tecnologias

* HTML5
* CSS3
* JavaScript
* Socket.IO
* Chart.js

## Recursos

* Atualização em tempo real;
* Gráficos dinâmicos;
* Controle operacional;
* Visualização espectral.
